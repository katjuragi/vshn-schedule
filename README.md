# Расписание АГТУ ВШН

Сайт показывает расписание групп из открытого [сервиса ВШН](https://qr.agni-rt.ru/schedule/). В Telegram и браузере используется один и тот же сайт.

## Публикация

1. Загрузите содержимое проекта в ветку `main` публичного репозитория GitHub. Сохраните папку `.github/workflows`.
2. В настройках репозитория откройте **Pages → Build and deployment → Source → GitHub Actions**.
3. Откройте **Actions → Расписание ВШН → Run workflow**. После завершения ссылка появится в шаге **Опубликовать** и в настройках Pages.
4. В чате с **@BotFather** выберите `/setmenubutton`, укажите своего бота, вставьте HTTPS-ссылку GitHub Pages и задайте текст кнопки «Расписание».

## Обновление

GitHub Actions запускает загрузку раз в час. Скрипт получает список групп и получает текущую неделю и пять следующих двумя запросами на группу. Данные предыдущей недели хранятся для навигации. Недели считаются по московскому времени.

Готовая версия расписания публикуется по адресу `schedule-data.json` внутри сайта. Следующий запуск использует её как резерв. При частичном сбое старые данные сохраняются для затронутых групп. При полном сбое уже опубликованная версия остаётся открытой. При первом запуске используется стартовая копия, если источник недоступен.

Для локального просмотра выполните `python3 -m http.server 4173` и откройте `http://localhost:4173/`. Скрипт `python3 sync_schedule.py` сохраняет свежие данные в `dist/schedule-data.json`.

Если запуск обновления задержался, в **Actions** можно посмотреть блок загрузки ВШН и запустить обновление вручную. В публичном репозитории GitHub может приостановить запуски по расписанию после 60 дней без активности.
